# Go Protocols

Focused, embeddable protocol libraries and tools in pure Go.

| Module | Description |
| --- | --- |
| [`irc`](./irc) | IRC client, server, bouncer, and protocol packages |
| [`torrent`](./torrent) | BitTorrent client library and CLI (BEP 3) |
| [`sftp`](./sftp) | SFTP client library and server |
| [`ftp`](./ftp) | FTP and FTPS client library and server |

Each directory is an independent Go module.
